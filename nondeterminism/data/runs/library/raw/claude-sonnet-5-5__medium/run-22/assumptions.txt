- Loan period is 21 days; the due date is the borrow date plus 21 days.
- A loan can be renewed at most 2 times; each renewal sets the due date to the renewal date plus 21 days.
- Renewal fails if anyone has a hold on the book, if the loan is already overdue (date after due date), or if the member does not have the book.
- Fine is 25 cents per full day late, charged at return, added to owed, and not charged on the due date itself.
- To avoid being harsh, the fine for a single loan is capped at 1000 cents.
- Fines are not charged while a book is still out; there is no fine for renewals.
- Borrowing fails if the member owes any money or has any overdue loan on another book.
- There is no limit on how many books a member can borrow.
- Borrowing fails if the book is already on loan, or if it is set aside for or queued for another member.
- When a book with a waiting line is returned, the first member in line gets it set aside for 3 days (readyUntil = return date + 3 days, inclusive).
- If the pickup window passes without a borrow, the hold is dropped and the next in line gets a new 3-day window starting from the end of the previous one; this is processed lazily on each call using its date.
- Borrowing the set-aside book removes that member's hold.
- A hold fails if the book is available with nobody queued, if the member already holds or has borrowed that book, or if the member or book is unknown.
- Holds are allowed even if the member owes fines.
- readyUntil is non-null only for the first in line when the book is on the shelf and set aside; otherwise null.
- payFine fails for unknown members, non-integer or non-positive amounts, and amounts greater than what is owed (no overpayment, no credit).
- Duplicate addBook/addMember ids fail; invalid or malformed dates fail with no change.
- getMember for an unknown member returns an empty record (no loans, owed 0, no holds) rather than failing.
- Loans are listed in borrow order; holds in book-addition order.
