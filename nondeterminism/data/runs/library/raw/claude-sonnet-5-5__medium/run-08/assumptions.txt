- Loan period is 21 days; due date is borrow date + 21.
- A book can be renewed at most 2 times; each renewal sets the new due date to renewal date + 21 days.
- Renewal is refused if anyone has a hold on the book, if the loan is overdue (date after due date), or if the member isn't the borrower.
- A return on the due date is not late; the fine is 25 cents per full day late.
- To avoid being harsh, the fine for a single loan is capped at 1000 cents.
- Fines are added to the member's owed balance at return time; nothing accrues while a book is still out.
- Owing money does not block borrowing, renewing, or holding. There is no limit on the number of loans.
- payFine requires a positive integer amount no larger than the amount owed; overpayment is rejected and nothing changes.
- Holds are allowed only on books that are currently on loan (or already have a queue), by a different member than the borrower, and only one hold per member per book.
- Hold queue is first-come-first-served; position 1 is next, and it includes the member whose copy is set aside.
- When a book with holds is returned, the first holder gets it set aside, with readyUntil = return date + 7 days (inclusive last pickup day).
- If the pickup window passes (date > readyUntil), that hold is dropped and the next holder gets a new window of 7 days starting the day after the expiry; this is processed lazily at each call with a date.
- A book set aside can be borrowed only by the member it is set aside for; that borrow removes their hold. A returned book with no holds is available to anyone.
- readyUntil is null for holds that are not first in line, or in the queue of a book still on loan.
- Duplicate or null ids on addBook and addMember are rejected; unknown members or books are rejected.
- Invalid or malformed dates are rejected with ok: false.
- Only the member who borrowed a book can return or renew it.
- getMember for an unknown member returns ok: false with empty loans and holds and owed 0. Otherwise it has no ok field.
- Loans and holds in getMember are listed in book insertion order.
