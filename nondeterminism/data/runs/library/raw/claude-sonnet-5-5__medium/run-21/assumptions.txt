- Loan period is 21 days; due date is borrow date + 21.
- A loan can be renewed at most 2 times; each renewal sets the new due date to renewal date + 21 days.
- Renewal is refused if anyone has a hold on the book, if the loan is already overdue, or if the renewal limit is reached.
- Fine is 25 cents per full day after the due date, charged at return; returning on the due date is free.
- To be lenient, the fine for a single loan is capped at 1000 cents.
- Fines are added to the member's owed balance when the book is returned.
- Borrowing is refused while the member owes more than 500 cents.
- A hold can only be placed on a book that is currently on loan to someone else; not if the book is available, if the member already has it, or if the member already holds it.
- Holds form a FIFO queue; position 1 is next.
- When a held book is returned, it is set aside for the first holder, who has through return date + 7 days (readyUntil) to pick it up.
- A set-aside book can be borrowed only by that member; others are refused.
- If the pickup window passes without a borrow, the hold is dropped on the next call with a later date. The next holder then gets readyUntil = the previous readyUntil + 7 days. If no one is waiting, the book becomes available.
- Borrowing a set-aside book removes the member's hold. Holders behind move up.
- readyUntil is non-null only for the member at the front of the queue while the book is set aside.
- There is no limit on the number of loans or holds per member.
- payFine rejects non-integer amounts, amounts ≤ 0, amounts above what is owed, and unknown members.
- Duplicate or missing ids in addBook/addMember are rejected, as are invalid dates in any call.
- Unknown members or books make an action fail.
- getMember for an unknown member returns ok:false with empty loans, owed 0 and empty holds; for a known member it also includes ok:true.
- returnBook on a failure returns fine 0.
- Loans and holds are listed in book insertion order.
