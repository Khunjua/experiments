- Loan period is 21 days; due date = borrow date + 21.
- Renewal allowed at most 2 times; each renewal sets the new due date to renewal date + 21.
- Renewal is refused if anyone has a hold on the book, if the loan is already overdue (date after due date), or if the member owes money.
- Fine is 25 cents per full day late; returning on the due date is free.
- To avoid harshness, the fine per loan is capped at 1000 cents.
- Fines are added to the member's owed balance at return; returnBook reports the fine for that return.
- Borrowing is refused if the member owes anything or has an overdue loan.
- No limit on the number of simultaneous loans.
- Unknown member/book, malformed dates, duplicate addBook/addMember, and missing ids return { ok: false }.
- Holds are only allowed on books that are out or set aside for someone else; not on an available book, not on a book the member has on loan, and not twice on the same book.
- When a book is returned and a queue exists, it is set aside for the first holder, who has through return date + 7 days (readyUntil) to pick it up.
- Only the first holder can borrow a set-aside book; borrowing removes their hold.
- If the pickup window passes (date > readyUntil), the hold is dropped automatically (applied lazily on every call). The next in line then gets 7 days starting the day after the previous expiry. If no one remains, the book becomes available.
- Hold position counts all holds in the line, including the one the book is set aside for (position 1). readyUntil is non-null only for that first holder when the book is set aside; otherwise null.
- payFine rejects non-integer, non-positive amounts and overpayments (more than owed), changing nothing.
- getMember on an unknown member returns { ok: false }. Loans are listed in borrow order; holds are listed in book-add order.
- Overdue loans never cause fines until returned; owed does not increase over time before return.
