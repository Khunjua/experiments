- Loan period is 21 days; due date is borrow date + 21 days.
- Maximum 2 renewals per loan; each renewal extends the current due date by 21 days.
- Renewal is refused if anyone is waiting on the book, if the loan is overdue, or if the renewal limit is reached.
- A fine is 25 cents per full day after the due date; returning on the due date is free.
- To avoid being harsh, the fine per loan is capped at 1000 cents.
- Fines are added to owed only when the book is returned; nothing accrues before that.
- A member who owes 1000 cents or more cannot borrow; a member can have at most 5 loans.
- Payments must be a positive integer no larger than the amount owed; otherwise the payment is rejected with ok: false.
- A hold can be placed only on an existing book that is currently on loan to someone else; no duplicate holds, and none on a book the member has on loan.
- Holds are served first-come first-served; position 1 is the head of the queue, including a book that is set aside.
- When a held book is returned, it is set aside for the first member, with readyUntil = return date + 3 days.
- If it is not picked up by readyUntil, that hold is dropped. The next member gets it set aside starting the next day, for 3 days (readyUntil = old readyUntil + 4). This is applied lazily on every call.
- A book that is set aside can be borrowed only by the member at the head of the queue, and borrowing removes their hold.
- A book that is on the shelf with no queue can be borrowed by anyone eligible.
- Duplicate or missing ids in addBook/addMember, unknown members or books, and malformed dates return ok: false.
- getMember for an unknown member returns empty loans, 0 owed, and empty holds.
- readyUntil is null for holds that are still waiting.
- Overdue loans do not block new borrowing, only the owed threshold does.
