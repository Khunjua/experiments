- Loan period is 21 days; due date is borrow date + 21.
- Maximum 2 renewals per loan; the new due date is the renewal date + 21 days.
- Renewal is refused if anyone has a hold on the book, if the loan is already overdue, or if the renewal limit is reached.
- Fine is 25 cents per full day late, with no fine on the due date itself.
- To avoid being harsh, the fine is capped at 1000 cents per loan.
- Fines are added to the member's owed balance when the book is returned.
- A member who owes any money cannot borrow, nor can a member with an overdue loan.
- A member can have at most 5 loans at once.
- A book can only be borrowed if it is not on loan. If it has a hold queue, only the member at the head can borrow it, and that member's hold is removed.
- When a book is returned and a queue exists, the head of the queue gets it set aside with readyUntil = return date + 7 days.
- If the pickup window passes unused (the day after readyUntil), that hold is dropped and the next member's readyUntil is the previous readyUntil + 7 days. This is evaluated lazily on each call using that call's date.
- A hold can only be placed if the book is on loan or already has a queue. A book that is on the shelf with an empty queue is refused.
- A hold is refused for a member who has the book on loan or already holds it.
- Hold position is the 1-based index in the queue, including the member whose copy is set aside.
- payFine requires a positive integer amount that does not exceed the amount owed. Overpayment is refused.
- Duplicate or missing IDs on addBook/addMember are refused.
- Invalid date strings make a dated action return { ok: false }.
- getMember for an unknown member returns empty loans and holds with owed 0.
- Returning a book not currently borrowed by that member fails.
