- Loan period is 21 days from the borrow date; the due date is borrow date + 21.
- A member may renew a loan at most 2 times; each renewal sets the due date to renewal date + 21.
- Renewal is refused if the loan is already overdue (date after due date), if the limit is reached, or if anyone is waiting on the book.
- Late fine uses a 3-day grace period: returns up to 3 days after the due date are free.
- Fine is 25 cents for each day beyond the grace period (day 4 late is the first charged day), capped at 500 cents per return.
- Fines are assessed only when a book is returned; owed never includes fines for loans still out.
- A book returned to a waiting queue is set aside for the first person in line, who has 3 days to pick it up, counting the return date as day 0 (last pickup day is return date + 3).
- If a set-aside hold is not picked up by its last day, the member loses the hold and the book passes to the next person in line with a fresh 3-day window starting the day after the lapse; if the line is empty, the book goes back on the shelf.
- A member can place a hold only on a book that is currently on loan to someone else; holds on shelf or set-aside books are refused.
- A member can have at most one hold (waiting or set aside) per book, and there is no limit on the number of holds or loans per member.
- Hold position is 1-based by line order; a set-aside hold is reported with position 0.
- A set-aside book can be borrowed only by the member it is set aside for; that borrow clears the hold.
- Borrowing, returning, renewing, and paying are not blocked by unpaid fines; no borrowing limit is imposed on members who owe money.
- payFine accepts only positive integer cents not exceeding the amount owed; anything else is refused and changes nothing (no overpayment or partial-invalid handling).
- getMember for an unknown member returns an empty result: no loans, owed 0, no holds.
- Member and book IDs must be non-empty strings; adding a duplicate ID or an invalid ID returns { ok: false }.
- Methods taking a date first apply any expired set-aside holds up to that date, so state reflects the call date.
- Dates are assumed to be well-formed 'YYYY-MM-DD' strings; no validation is performed on them.
- Day arithmetic uses UTC so results do not depend on the host time zone.
- A return or renewal is only accepted from the member who currently holds the loan.
