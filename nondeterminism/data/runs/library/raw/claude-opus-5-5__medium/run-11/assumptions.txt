- Loan period is 21 days; due date = borrow date + 21 days, and returning on the due date is not late.
- "A couple of times" means at most 2 renewals per loan.
- Each renewal extends the current due date by 21 days (not counted from the renewal date).
- Renewal is refused if anyone holds the book, if the loan is already overdue, or if the member owes 1000 cents or more.
- Fine is 25 cents per day late, with no grace period, capped at 1000 cents ($10) per returned item ("not harsh").
- Fines are charged only when the book is returned; unreturned overdue books do not add to "owed" until returned.
- Members owing 1000 cents or more cannot borrow; smaller balances do not block borrowing.
- No limit on the number of books a member may borrow at once.
- A hold can be placed only if the book is on loan or already has a waiting line; not if it is sitting on the shelf available.
- A member cannot hold a book they currently have borrowed, nor hold the same book twice.
- Holds are served first-come, first-served; position 1 is next in line (or the one it is set aside for).
- When a held book is returned, it is set aside for the first member in line until the return date + 7 days (inclusive).
- If not picked up by readyUntil, that hold is dropped and the book is set aside for the next member for another 7 days, counted from the previous readyUntil; if no one is left, the book becomes available to anyone.
- While set aside, only that member can borrow the book; borrowing it removes their hold.
- Members cannot cancel holds (no method exists for it).
- Payments must be positive integers and cannot exceed the amount owed; overpayment is refused.
- Adding a book or member with an existing id, or a non-string/empty id, returns { ok: false }.
- Unknown member/book, invalid calendar dates, or dates earlier than a previous call return { ok: false }.
- getMember for an unknown member returns { ok: false }; successful getMember responses also include ok: true.
- getMember lists loans in borrow order and holds in book-insertion order.
- Successful responses include ok: true; failures include an informational reason field.
