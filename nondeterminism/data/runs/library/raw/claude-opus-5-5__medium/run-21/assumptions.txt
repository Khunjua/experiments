- Loan period is 21 days; due date = borrow date + 21; returning on the due date is not late.
- A loan can be renewed at most 2 times; each renewal adds 21 days to the current due date (not to the renewal date).
- Renewal is refused if anyone has a hold on the book, if the book is overdue, or if the caller is not the borrower.
- "Not harsh": 2-day grace period (returning 1–2 days late costs nothing; beyond that every late day including the grace days is charged at 25 cents), and the fine per loan is capped at 1000 cents.
- Borrowing is blocked when the member owes 1000 cents or more; members may have at most 5 books at once.
- Holds may only be placed on a book that is on loan or set aside for someone else; not on an available book, not on a book the member currently has, and not twice by the same member. No limit on number of holds.
- When a book with holds is returned, it is set aside for position 1; readyUntil = return date + 6 (7 pickup days including the return day).
- If a set-aside book is not picked up by readyUntil, that hold is removed and the book is set aside for the next in line for another 7 days starting the day after; this is evaluated lazily on each call using its date.
- A set-aside book can only be borrowed by the member it is set aside for; borrowing it removes their hold. Other holders keep their place.
- readyUntil is non-null only for the position-1 member when the book is actually set aside.
- payFine rejects non-integer, zero, negative, or greater-than-owed amounts.
- getMember returns { ok: false } for an unknown member and includes ok: true on success; loans and holds are listed in the order they were created.
- IDs must be non-empty strings or finite numbers; adding a duplicate book or member returns { ok: false }.
- Invalid or impossible dates return { ok: false }.
- Unknown member or book in any call returns { ok: false }.
- There is a single copy per bookId; books and members cannot be removed.
