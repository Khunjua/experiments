- Loan period is 21 days; dueDate = borrow date + 21 days.
- "A couple of times" means at most 2 renewals per loan.
- A renewal extends the current due date by 21 days (not from the renewal date).
- Renewal is refused if any other member holds the book, if the loan is already overdue, or if the member owes 1000 cents or more.
- Fine is 25 cents per day after the due date; returning on the due date is not late; no grace period.
- "Not harsh" means a cap of 1000 cents (10 dollars) on the fine for a single loan.
- Fines are charged when the book is returned, not accrued while it is still out; owed counts only charged fines.
- A member cannot borrow if they owe 1000 cents or more or if they currently have an overdue loan; there is no limit on the number of loans.
- Holds may only be placed on a book that is out (on loan or set aside for someone); placing a hold on an available book fails.
- A member cannot hold a book they currently have on loan, and cannot hold the same book twice.
- Placing a hold is not blocked by owed money or overdue loans.
- When a held book is returned, it is set aside for the first member in line; readyUntil = return date + 7 days (inclusive).
- If the pickup window expires, that hold is dropped and the book is set aside for the next member, with a new window starting the day after the previous one ended (readyUntil = previous readyUntil + 8 days); expiry is processed lazily using the date of each call.
- A set-aside book can only be borrowed by the member it is set aside for; borrowing it removes their hold.
- Hold positions count from 1 in the order holds were placed; the member with the set-aside book is position 1.
- payFine requires a positive integer amount not exceeding what is owed; overpayment fails.
- Adding a book or member with an existing ID fails; unknown member or book IDs make any action fail.
- Returning or renewing a book that this member does not have on loan fails.
- An invalid date string makes a call fail with { ok: false }.
- getMember for an unknown member returns { ok: false }; otherwise it also includes ok: true.
- getMember lists loans in borrow order and holds in the order they were placed.
- Each library has a single copy per bookId.
