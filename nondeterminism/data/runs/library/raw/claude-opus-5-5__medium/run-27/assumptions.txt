- Each bookId is a single physical copy; ids must be non-empty strings or finite numbers; adding a duplicate id fails.
- Loan period is 21 days: dueDate = borrow date + 21 days; returning on the due date is not late.
- "A couple of times" means at most 2 renewals per loan.
- A renewal sets the new due date to renewal date + 21 days (not stacked on the old due date).
- Renewal is refused if anyone has a hold on the book, if the loan is already overdue, or if the member owes 1000 cents or more.
- Fine is 25 cents per day past the due date, with no grace period.
- "Not harsh" is implemented as a cap of 1000 cents (10 dollars) on the fine for any single return.
- Fines are charged only when the book is returned; nothing is owed for an overdue book still out.
- A member owing 1000 cents or more cannot borrow or renew.
- A member can have at most 5 books on loan at once.
- Holds can be placed only when the book is on loan or already has a waiting line; a hold on a freely available book fails.
- A member cannot hold a book they currently have on loan, and cannot hold the same book twice.
- When a held book is returned, it is set aside for the first person in line for 7 days, the return day included (readyUntil = return date + 6).
- If the pickup window passes, that hold is dropped and the book is set aside for the next person, with a 7-day window starting the day after the previous window ended.
- While a book is set aside, only that member can borrow it; borrowing it removes their hold.
- Holds have no expiry other than the pickup window, and there is no way to cancel them, since there is no method for it.
- Hold position counts the member who has the book set aside as position 1.
- payFine requires a positive integer amount no greater than what is owed; overpayment fails.
- Members and books cannot be removed.
- An invalid or missing date string, or an unknown member or book, returns { ok: false }.
- getMember for an unknown member returns { ok: false }.
- getMember lists loans in borrow order and holds in the order they were placed.
- Methods with a date apply expired pickup windows up to that date before acting.
