- Each bookId is a single physical copy; adding an existing bookId or memberId returns { ok: false }.
- IDs must be non-empty strings or finite numbers.
- Loan period is 21 days; due date = borrow date + 21; returning on the due date is not late.
- "A couple of times" means at most 2 renewals per loan.
- A renewal adds 21 days to the current due date (not to the renewal date).
- Renewal is refused if anyone holds the book, if the loan is already overdue, or if the member owes 1000 cents or more.
- Late fine is 25 cents per day after the due date, no grace period, capped at 500 cents per loan ("not harsh").
- Fines are charged only at return time; getMember's owed does not include fines accruing on books still out.
- Members owing 1000 cents or more cannot borrow, renew or place holds; returning and paying are always allowed.
- No limit on the number of books a member can have out at once.
- A hold can only be placed on a book that is on loan or already set aside/held for others; not on a book sitting free on the shelf, not by the current borrower, and not twice by the same member.
- When a held book is returned it is set aside for the first in line; readyUntil = return date + 7 days (inclusive).
- If the pickup window passes, that hold is dropped and the book is set aside for the next in line starting the day after the previous window ended, again for 7 days; expiries are processed lazily on any dated call.
- Only the member it is set aside for can borrow a set-aside book; borrowing it removes their hold.
- Positions are 1-based; the member a book is set aside for is position 1.
- payFine requires a positive integer amount not exceeding what is owed; overpayment is rejected.
- Invalid dates, or dates earlier than the previous call, return { ok: false }.
- getMember for an unknown member or invalid date returns { ok: false, loans: [], owed: 0, holds: [] }; successful getMember also includes ok: true.
- getMember lists loans in borrow order and holds in the order books were added.
