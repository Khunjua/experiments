- Loan period is 21 days; the due date is the borrow date + 21 days.
- "A couple of times" means at most 2 renewals per loan.
- A renewal adds 21 days to the current due date, not to the renewal date.
- Renewal is refused if anyone holds the book, if the loan is already overdue, or if the member owes 1000 cents or more.
- To be "not harsh", there is a 2-day grace period: a return up to 2 days after the due date has no fine. A later return is charged 25 cents for every day late, grace days included.
- The fine per return is capped at 1000 cents.
- A fine is charged only when the book is returned. `owed` does not include fines still building up on loans that are out and overdue.
- A return on the due date is not late.
- A member cannot borrow or place a hold while owing 1000 cents or more, or borrow while having any overdue book.
- A member may have at most 5 books on loan and at most 5 holds at a time.
- A hold can only be placed on a book that is on loan or set aside for someone. A book on the shelf must be borrowed instead.
- A member cannot hold a book they currently have, or hold the same book twice.
- Holds form a first-come, first-served line per book. Position 1 is the front of the line, including a member whose book is set aside.
- When a held book is returned, it is set aside for the first member in line. That member can pick it up through return date + 6 days (7 days in total, inclusive).
- If the pickup window ends without a pickup, that hold is dropped. The book is then set aside for the next member for another 7 days, starting the day after the previous window ended. When no one is left in line, the book goes back on the shelf.
- While a book is set aside, only that member can borrow it. Borrowing it removes their hold.
- `readyUntil` is null for every hold that is not currently set aside.
- A member cannot cancel a hold; the interface has no method for this.
- Overpayment is refused: `payFine` fails if the amount is not a positive integer or is more than the amount owed.
- IDs must be non-empty strings. Adding a book or member whose ID already exists fails.
- Unknown members or books, invalid dates, and dates earlier than the previous call return `{ ok: false }`.
- `getMember` for an unknown member returns `{ ok: false }`.
- `getMember` lists loans and holds in the order the books were added to the library.
- Members and books cannot be removed; the interface has no method for this.
