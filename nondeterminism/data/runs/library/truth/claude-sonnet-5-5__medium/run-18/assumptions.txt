- Expiry of set-aside books is processed lazily at the start of every call, using that call's date. A set-aside is expired when the call date is later than readyUntil.
- The member a book is set aside for stays in the hold line at position 1 until they borrow it or it expires. Their getMember hold entry shows readyUntil.
- When a set-aside expires, the next member's readyUntil is the old readyUntil + 3 days, even if that is already in the past. Expiry then chains in the same call.
- A fine is 25 × days late when the book is 3 or more days late, capped at 500. Fines apply at return time and add to owed.
- Duplicate addBook or addMember is refused.
- Unknown members or books are refused for every method. getMember for an unknown member returns { ok: false }.
- Renewal requires that the book's hold line is empty. Only the member who has the book on loan can renew or return it.
- payFine requires an integer amount greater than 0 and no greater than owed.
- A member who owes 1000 or more is refused borrowing, even for a book set aside for them.
- The 5-book limit counts current loans only. Set-aside books don't count.
- A member can hold a book that is set aside for another member, joining the end of the line.
- Dates are assumed to be valid 'YYYY-MM-DD' strings and are not validated.
