- Duplicate addBook or addMember returns { ok: false } and changes nothing.
- Operations on an unknown member or book return { ok: false }; getMember for an unknown member returns { ok: false }.
- Hold expiry is applied lazily at the start of every call, using that call's date; a set-aside period ends when date > readyUntil.
- A member whose hold is set aside is at position 1 and is the only one with a non-null readyUntil for that book.
- A hold on a book set aside for another member is allowed and joins the end of the line.
- A member who is set aside a book but owes 1000 cents or more, or has 5 loans, still cannot borrow it; their hold keeps running until it expires.
- After the set-aside member borrows the book, the remaining holds wait for the next return. They are not set aside while the book is on loan.
- A fine applies only when the return is 3 or more days late. It is 25 cents times all late days, capped at 500.
- payFine requires an integer amount greater than 0 and no more than the amount owed.
- Renewing is refused if anyone holds the book, including a hold that is currently set aside, though a set-aside book is not on loan anyway.
- Renewal count does not reset. A loan starts at 0 renewals and a new borrow creates a new loan.
