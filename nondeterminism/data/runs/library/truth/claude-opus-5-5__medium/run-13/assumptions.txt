- Adding a book or member whose id already exists is refused; ids must be non-empty strings or finite numbers.
- Any call referring to an unknown member or unknown book is refused with { ok: false }.
- Any call with a missing or invalid date is refused; getMember with an invalid date just skips hold expiry processing.
- getMember for an unknown member returns { ok: false, loans: [], owed: 0, holds: [] } instead of throwing.
- Expired set-asides are processed lazily at the start of every call, using that call's date, before the action is checked; the chain of +3-day extensions is followed as far as needed.
- A set-aside counts as expired only on a date strictly after readyUntil (readyUntil is inclusive).
- When a member's set-aside expires, only their hold on that book is dropped; no fine or other penalty applies.
- A member who has a book set aside for them may still borrow it only if the normal loan rules allow (fewer than 5 loans and owing less than 1000 cents); if refused, the set-aside stays in place.
- Borrowing a book the member already has on loan is refused (the book is on loan).
- Borrowing is blocked when owed >= 1000 cents; only owed amount blocks borrowing, not overdue books.
- Days late = return date minus due date; when more than 2 days late, all late days are charged at 25 cents, capped at 500.
- A failed returnBook includes fine: 0; a failed payFine for a known member includes the current owed.
- The renewal count belongs to a single loan and starts at 0 on each new borrow.
- Renewal is refused if the book has any hold, including when the holder is already in line.
- Placing holds is not restricted by the amount owed or by the number of loans or holds the member has.
- A member to whom the book is currently set aside cannot place another hold on it (duplicate hold).
- A hold's position in placeHold is its place in that book's line at the time it is placed (line length after adding).
- In getMember, readyUntil is shown only for the position-1 member while the book is set aside (not on loan); otherwise it is null.
- Payment amounts must be positive integers no greater than the amount owed; non-integer amounts are refused.
- Holds in getMember are listed in book insertion order.
